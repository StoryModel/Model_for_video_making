# AI Manhwa Video Generator

A local AI Manhwa / Manga / Anime style video generator.

This project allows you to:

- Create local projects
- Upload main character image
- Write story script or upload PDF/TXT/DOCX
- Split story into scenes
- Generate image prompts
- Generate placeholder images
- Generate free voice using Edge-TTS
- Build MP4 videos using FFmpeg
- Download final video in 720p and 360p
- Resume old projects
- Delete projects after work is done
